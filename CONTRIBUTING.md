# Contributing

[Working on Lethal](AGENTS.md) describes project priorities, performance work, and verification of requested results.

## Code design

Use the [code design guide](docs/contributing/code-design.md) when choosing names, organizing control and data flow,
or deciding where an abstraction or dependency belongs.

## Comments & Documentation

Use the [documentation guide](docs/contributing/documentation.md) when writing API contracts, explaining a design
choice, or deciding whether a worked example would help a reader.

## Mixin Rules

Follow the [Mixin rules](docs/contributing/mixins.md) for interface injection and access transformations.

## Resource cleanup and unrecoverable failures

Follow the [resource lifetime rules](docs/contributing/resource-lifetime.md) for project-owned destructors,
fallible operations, and cleanup failures.
